    PERSISTENCIA DEL SISTEMA EN GIT

    Guardar Progreso y Niveles en el Repositorio Git

    Todos los avances de semana, ascensos de nivel, nuevos usuarios y multiplicadores se guardan instantáneamente en tu navegador y se sincronizan con el archivo versionado data/prexia-users-db.json del repositorio Git.

    1. Guardado y Commit Directo en Git Local (Recomendado en tu computador)

    Si ejecutaste python3 scripts/servidor_prexia_git.py, este botón escribe directamente en data/prexia-users-db.json y ejecuta git add + git commit (y opcionalmente git push).

    2. Commit Directo a GitHub desde el Navegador (GitHub Pages / API REST)

    Si estás usando la plataforma publicada en GitHub Pages (carlmarx17/proyectoprexia), ingresa un Personal Access Token (PAT) de GitHub para hacer commit directo de data/prexia-users-db.json a la rama main.

    3. Descargar / Importar prexia-users-db.json o Restaurar Base

    Descarga el archivo JSON actualizado para reemplazar data/prexia-users-db.json o carga una copia previa.

    git add data/prexia-users-db.json && git commit -m "chore(poa): actualizar progreso usuarios PREXIA" && git push
